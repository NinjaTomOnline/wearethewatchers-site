Order tee, hoodie, hat, and desk mat samples before paid traffic; photograph front, back, stitching, print placement, packaging, and tracking emails.

Select patch provider

Pick woven/embroidered patch vendor, lock size/backing/border specs, upload patch art, and order a proof before listing it as buyable.

Brand Shopify product handles

Rename default Shopify handles to watchers-tee, hold-the-line-hoodie, custos-hat, and oversight-desk-mat; create redirects from the current handles.

Build product detail pages

Add static product-detail pages with sizes, materials, print method, care instructions, fulfillment caveats, and sample-QA status.

Connect email capture

Choose Shopify Forms, Beehiiv, Klaviyo, or Mailchimp; connect Join the Watch and write a 3-email welcome sequence.

Verify support and privacy mailboxes

Set up support@wearethewatchers.com and privacy@wearethewatchers.com, test delivery, then publish contact links.

Add privacy-safe analytics

Install Plausible or GA4 only after privacy copy names the tool; add conversion events for view product, join waitlist, and checkout click.

Create launch bundles

Build Watcher Kit and Oversight Desk Kit bundles after product samples pass QA, with simple savings and stronger AOV.

Shoot short-form launch clips

Turn the mockups into 8-12 second videos around Power needs a witness, Not followers. Watchers., and We hold the line.

Build ad test matrix

Run 3 hooks x 3 creatives x 2 audiences before scaling: dev/builders, AI governance/operators, and dark streetwear/cyberpunk buyers.

Add UTM tracking plan

Create UTMs for social, ads, email, and creator posts so Shopify and analytics can identify which message sells.

Create founder/oath page

Publish the CUSTOS origin, ethics, and lore without over-explaining; make it feel like a manifesto, not a corporate about page.

Lock legal/risk review

Run trademark/domain/social-handle clearance for CUSTOS and WE ARE THE WATCHERS before scaling inventory or ads.

Prepare support macros

Draft fast replies for sizing, POD production time, shipping/tracking, damaged item, wrong item, and return/refund questions.

Build sample-QA checklist

Create a pass/fail checklist per SKU: print sharpness, alignment, wash feel, embroidery readability, packaging, and photo evidence.

Create launch calendar

Schedule prelaunch waitlist, soft launch, sample-photo reveal, first ad tests, creator outreach, and second-drop tease.

Plan second drop

Decide whether Drop 2 is patches/stickers, a premium heavyweight tee, a poster/desk setup line, or a limited numbered piece.
